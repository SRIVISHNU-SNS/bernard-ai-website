# Bernard

Minimal image-led page built with the supplied balloon artwork.

- `pnpm dev:static` — run locally on port 3000.
- `pnpm check` — TypeScript check.
- `pnpm build:static` — build files into `dist/public/`.

The installer and Gemini 4 local runtime are not included. The two controls show those availability states without pretending they are connected.

Public source: https://github.com/SRIVISHNU-SNS/bernard-ai-website
